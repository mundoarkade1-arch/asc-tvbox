# Instruções para agentes de IA

## Antes de qualquer coisa
1. Leia README.md
2. Leia docs/STATUS.md (estado atual e próximos passos)
3. Leia docs/TARGET_DEVICES.md (restrições dos aparelhos-alvo)
4. Leia docs/ORIGINAL_APP.md (o que o app original faz)
5. Consulte docs/DECISIONS.md antes de propor mudanças de arquitetura

## Regras
- Este app é para TV boxes ANTIGOS: priorize compatibilidade e baixo uso de memória.
- O dono do projeto é leigo em programação: explique em português simples, passo a passo.
- Não adicione dependências sem justificar em docs/DECISIONS.md.
- Ao terminar uma tarefa, atualize docs/STATUS.md.
- Nunca coloque senhas, chaves de API ou tokens no repositório.
